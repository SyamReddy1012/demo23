What is FOSS?

The ideas behind free and open source software, and how projects actually work.

FREE SOFTWARE

Freedom, not price

Freedom to use, study, modify and share. "Free" is about freedom, not necessarily price.

OPEN SOURCE

Source you can see

Source code is available under a license that allows permitted use, modification and redistribution.

USESTUDYMODIFYSHARE

Sources: gnu.org, opensource.org

FOSS vs Proprietary

Both models have a place.

FOSS / Open SourceProprietary
Source code available under a licenseSource code generally closed
Community contribution possibleControlled by the vendor
Can often be modifiedModification restricted
Transparent development possibleDevelopment controlled privately
Many projects are community-drivenUsually company-driven

Examples: FOSS

LinuxFirefoxVLCBlenderLibreOfficePostgreSQL

Examples: Proprietary

WindowsMicrosoft OfficeAdobe PhotoshopFinal Cut Pro
Both are valid choices. Neither is "good" or "bad" by default.

How Open Source projects work

The contribution lifecycle, from idea to release.

IdeaSpot something to improve
IssueDescribe it on GitHub or GitLab
ForkCopy the repo to your account
CodeMake your change
Pull RequestPropose it to the project
ReviewMaintainers give feedback
MergeAccepted into the project
ReleaseShipped to users
